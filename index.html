Projects

CapAble

A sign language translator for the mute that uses a Raspberry Pi 5 and a camera to translate sign language into text.

It uses a machine learning model to recognize sign language gestures and convert them into text.

It is designed to help people who are deaf or hard of hearing communicate more easily.

VTracks

This is a shoe mounted device that helps blind individuals to navigate and inform them about their surroundings.

It uses ultrasonic sensors to detect obstacles and provides haptic feedback to the user.

It has build in magnets for easy clip on

We used open street map and a Neo-6m GPS module to provide accurate location information.

Algearythm

This is a floatable device that collects red tide algae on the ocean surface.

It is build with lego technic bricks for lightweight design and fast prototyping.

It is connected to an app called Blynk for us to control it wirelessly

Tips

Tips and tricks the might be helpful!

Whenever you are working on a project, always find online forums/videos(reddit or github) for help instead of AI. I found that they are normally better at providing practical solutions.

For hardware projects try learning C++ as early as possible. Trust me it will not be fun when you are debugging AI generated code that you dont understand

Some youtube channel that I used early on: Robonyx| techiesms| Core Electronics
